- 후보 `.pt`는 `state_dict`와 메타데이터를 담은 래퍼다. 현행 [ai_runtime.py](../coatdesk_v2/ai_runtime.py)는 세 파일을 순수 state dict로 로딩한다. **이름만 바꿔 복사하면 안 된다.** 배포용 형식 변환 또는 검증된 로더 대응과 manifest 해시 갱신이 필요하다. 보존한 실험 후보 자체는 수정하지 않는다.

## 4. 본 앱 UI 요구사항

상세는 [UI 개선 계획](UI_IMPROVEMENT_PLAN_20261102.md). 구현 진입점은 [Main.qml](../coatdesk_v2/qml/Main.qml), [GarmentCard.qml](../coatdesk_v2/qml/GarmentCard.qml), [PhotoPane.qml](../coatdesk_v2/qml/PhotoPane.qml), [backend.py](../coatdesk_v2/backend.py)다. 현재 백엔드에는 옷 `selected` 상태와 성별/사이즈/연령 필터만 있으므로 화면만 숨기는 것으로 완료하지 않는다.

1. **하단 작업 탭과 X 버튼 개선:** 요즘 웹사이트처럼 간결한 형태를 원한다. Fluent 2 탭은 참고 디자인이며 React나 새 UI 라이브러리로 전환하라는 요청이 아니다. 활성 탭을 명확하게 구분하고 작은 닫기 아이콘의 클릭 영역·키보드 접근성을 확보한다. 탭 닫기는 작업 기록 삭제와 구분한다. 홈·탭 전환·작업 기록·많은 탭/긴 이름을 유지한다.
2. **옷 카테고리 필터 추가:** 전체/자켓/코트/조끼/기타. 기존 성별·사이즈·성인/아동 필터와 AND로 적용하고 저장/복원·초기화·과거 저장값 호환을 포함한다.
