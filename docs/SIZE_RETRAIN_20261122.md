## 합성 제작·검수

imagegen 스킬의 기본 내장 ImageGen 도구만 사용했다. 새 API, CLI, 패키지, 외부 유료 서비스는 추가하지 않았다. 이전 3개 전체 프레임 시안은 학습에 사용하지 않았다.

학습 부모의 판넬 입력을 사용해 60/70/2XS 각각 독립 부모 그룹 6벌, 총 18개 기본 합성을 생성했다. 60/70 부모는 실제80/90, 2XS 부모는 여성 XS/S다. 60/70에는 같은 6부모를 사용하지만 목표당 독립 부모는 6벌이며 밝기 변형을 별도 부모로 세지 않는다. 개발/최종 사진이나 그 부모는 합성 학습에 사용하지 않는다.

생성 출력은 크기가 달라 512로 재표본화한 후, ImageGen이 만든 글자 및 원래 글자의 합집합과 5px 안티앨리어싱 여유만 원래 판넬에 합친다. 문자 주변 종이의 채널별 중앙값 비율로 국소 밝기를 맞춘다. 새 글꼴이나 글자를 프로그램으로 그리지 않는다. 머리·옷·배경은 원래 입력 픽셀을 보존하며 문자 마스크 밖 차이는 정확히 0이다. 18장 최종 합성의 글자·굵은 산세리프 형태·판넬 구조를 Codex가 육안 확인했다. 독립된 사람 검수라고 주장하지 않는다.

원본 코드·부모 그룹·원본 해시·실제 생성 프롬프트·생성 원본·차이·검수는 `synthetic/manifest.json`과 `synthetic/generated/`에 보존한다. `synthetic/review-contact.jpg`는 최종 검수 화면이다. 재표본화 진단은 실사 부모 및 합성 판넬의 동일 업/다운샘플 처리 전후를 비교한다. 합성의 학습 적합도 진단은 실사 성인2XS 정확도나 독립 평가가 아니다.

## 구조·학습 계약

현행 기준은 `dist-releases/v2-50c3b52756d1/CoatDesk2/_internal/resources/ai`의 실제 18종이다. 기본 `resources/ai`의 이전17종을 기준으로 쓰지 않는다. 기준 manifest의 모든 모델 해시를 확인했다.

PhotoClassifier의 ResNet18 stride16·공간 attention과 판넬 입력을 유지한다. 출력 순서는 아래20종이다.

`60,70,80,90,100,110,120,130,140,150,160,170,2XS,XS,S,M,L,XL,2XL,3XL`

현행18종의 출력 가중치/편향은 클래스 **이름**으로 새 위치에 복사하고 60/2XS만 초기화한다. ImageNet 평균(.485,.456,.406) / 표준편차(.229,.224,.225) 정규화, 입력512다. 클래스 대응·기존 특징 가중치 불변은 테스트로 확인했다.

매 epoch 학습용 실사 원본 각각1회 + 랜덤 증강2회, 합성 기본본도 각각1회 + 증강2회다. 총6,054개 입력이며 무작위 순서로 중복 없이 처리한다. 기존 photometric `change()` 범위에서 밝기±20%, 대비-15%, 색온도, 좌우 그림자≤25%, 약한 흐림을 사용한다. 글자 반전·삭제·기하 잘림은 없다. strength .25~1로 매회/원본/변형별 시드를 달리한다.

AdamW lr5e-5 / weight decay1e-4, cosine decay5e-6, batch16, AMP, 고정 BatchNorm, 최대16epoch, 최소6epoch 이후 개발4회 미개선 시 정지한다. 클래스별 제곱근 역빈도 가중치(상한8) CE에 공통 실사18종의 기존 모델 KL 보조 손실(.2, T=2)을 더한다. 회차 선택은 개발 원본/어둠/왼쪽그림자900조건의 정확도와 지원 클래스 macroF1 평균으로만 결정한다. 최종 자료는 회차/임계값 선택에 사용하지 않는다.

## 비교·인계 계약

학습 완료 후 같은 개발/최종 사진에 원본+고정8변형의9조건을 적용한다. 변형은 1080 전체 사진에 적용하고 각 조건에서 현행 판넬 검출을 다시 실행한다. 검출기·성별/연령은 양쪽에 공유하고 사이즈 모델만 바꾼다. 원문 판독 및 아동60/70→2XS,80/90→XS,100/110→S,120/130→M,140/150→L,160→XL,170→2XL 변환 후 업무 사이즈를 함께 비교한다.

전체·공통18종·실사60/70·성인/아동·원본/9조건별 정확도, 지원 클래스 macroF1, 클래스별 precision/recall/F1, 혼동표, 기존만/신규만 정답, 자동처리·오답·확인 필요, 실패, 실행시간을 저장한다. 자동 처리 범위는 판넬/성별연령/사이즈이며 카테고리와 아동 성별 사람 확인은 별도다. 현재90/90/90과 개발에서만 선택한 무관측오류 사이즈 기준을 모두 보고한다. 개발 무오류는 미래 오답0 보장이 아니다.

실제 CPU `Models.analyze`는 대표 클래스·희소·불일치 사진을 같은9조건으로 확인한다. 신규20종은 격리된 인스턴스의 분류기와 클래스 목록에 주입한다. 현재 앱 로더는17/18종만 받으므로 후보 파일을 그대로 앱에 교체할 수 없으며 별도 통합 승인이 필요하다.

## 재현·재개

저장소 루트 PowerShell에서 기존 환경만 사용한다.

```powershell
.local/ab-venv/Scripts/python.exe -m scripts.size_retrain_20261122 prepare
.local/ab-venv/Scripts/python.exe -m scripts.size_retrain_20261122_synthetic prepare
# 실제 최종 이미지 검수 후 accept (원래 18개 ImageGen 출력과 프롬프트는 결과 폴더에 보관)
.local/ab-venv/Scripts/python.exe -m scripts.size_retrain_20261122_synthetic accept
.local/ab-venv/Scripts/python.exe -u -m scripts.size_retrain_20261122_fit train
.local/ab-venv/Scripts/python.exe -u -m scripts.size_retrain_20261122_evaluate
```

`resume.pt`는 마지막 완료 epoch의 모델·옵티마이저·스케줄러·AMP·CPU/CUDA 난수 상태와 동결/합성 해시를 보관한다. 같은 train 명령으로 완료 epoch 다음부터 재개한다. 중간 epoch에서 중단하면 해당 epoch 전체를 다시 실행한다. 원래 fit 소스는 `source-used-for-fit/`에 보존하며 이후 unused import 정리만 있다. GPU 잠금은 프로세스 종료 시 자동 해제된다. 장시간 실행은 콘솔을 띄우지 않는 exec 세션으로 유지하고 PID/로그/체크포인트를 확인한다.

PyTorch2.11.0+cu128, torchvision0.26.0+cu128, Pillow13.0.0, RTX3060 12GB를 확인했다. 학습 환경에 pytest가 없어 기존 `.venv`의 pytest 모듈 경로만 추가해 CUDA 환경에서 테스트를 실행한다. 설치는 하지 않는다.
