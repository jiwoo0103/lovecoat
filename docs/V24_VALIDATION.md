## 2.4.1 후속 요구사항

- 현재 선택한 목록 항목은 파란 배경·흰 글씨, 일반 항목은 흰 배경·진한 글씨, 호버/키보드 이동은 연한 파란 배경·진한 글씨입니다. 카드·일괄 입력·분류 필터·각도 목록에 동일하게 적용합니다. 카드 재사용 뒤에도 현재 값에 맞춰 갱신합니다.
- 엑셀의 번호 폴더 ‘누락’ 숫자는 표시하지 않습니다. 현재 번호 범위에서 사용할 사진이 없는 폴더를 `사진 없는 폴더 N개`로 0개일 때도 표시하고 번호를 안내합니다. 부분 각도 누락이나 폴더 자체가 없는 번호를 이 숫자로 세지 않습니다. 에러번호로 제외한 폴더도 해당 범위 안이면 사진 상태를 안내합니다.
- 작업 메뉴에서 시작·끝 번호와 에러번호를 함께 변경합니다. 유효한 범위를 다시 스캔한 뒤 하나의 SQLite 트랜잭션으로 적용합니다. 기존 값·검수·AI 결과는 보존하고 신규 옷은 미분석으로 추가합니다. 범위 밖 기록은 보관하며 현재 사진/분석/엑셀 대상에서 제외합니다. 기존 폴더가 없어지면 기록을 보관하되 현재 대상에서 빼고, 같은 코드로 돌아오면 복원합니다. 저장된 엑셀은 바꾸지 않습니다.
- 역전 범위·과도한 범위·범위 밖 에러번호·중복/충돌 코드·사진 검사 실패는 기존 작업을 보존하고 저장을 거부합니다. 범위 변경은 입력 실행 취소 대상이 아니며, 범위를 다시 지정해 복원합니다.
- 새 집중 테스트 11개에서 범위 확대/축소/복원, 원자적 실패, 기존 검수/모델/다른 작업 보존, 엑셀 미리보기 무효화, 0개 사진 상태 표시와 드롭다운 색상을 검증했습니다. 최종 릴리스 검증은 완료 후 아래에 기록합니다.


### 추가 반영: 소매 기준 설정

소매 기본 기준은 사용자 후속 요청에 따라 90%이며 분석 기준 창에서 1~100%로 변경·저장합니다. 기장은 90%를 유지합니다. 기존 카테고리 점수는 새 기준으로 재판단하고 AI 출처의 값과 확인 필요 상태를 갱신합니다. 수동·확인한 값은 보존하며 설정은 재실행 후 복원합니다. 캐시 키와 결과에 실제 적용한 소매/기장 기준을 포함합니다. 최초 소매 95%·기장 80% 및 중간 95%/90% 실험·검증 기록은 덮어쓰지 않았습니다. 고정 CPU 141벌 예측에 90%/90%를 적용해도 자동 134·확인 필요 7벌이며 자동 엄격 129/134·경계 허용 132/134입니다. 새 촬영 자료 평가가 아닙니다.

소매 기본값·기준 변경 후 저장 결과 재판단·수동 확인 보존·재실행 복원·잘못된 기준의 원자적 거부와 실제 QML 설정 버튼을 추가 검증했습니다. 관련 전체 회귀 테스트 105개와 Ruff·diff 검사가 통과했습니다. 소매 90% 기본 정책으로 실제 CPU 6벌의 중단·재개·캐시·강제 재분석·기준 변경 반복 검사도 통과했습니다(`.local/v241-sleeve-resume/report.json`).
