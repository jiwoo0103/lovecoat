# 외투 작업실 2.6.0 설치 검증

2026-11-04에 2.6.0 Windows 설치파일을 생성했다. 판넬·성별/연령·사이즈는 `20261102-robust-four-models` 후보를 사용한다. 카테고리는 2.5.0 패키지에 포함된 소매·기장 모델과 정책·전처리 자산을 그대로 사용한다. 카테고리 모델 SHA-256은 `d48df504df994fa3414dba4e4efd979cd0080162883e7dd66b703e3d63b569fa`다.

배포용 모델은 `scripts/prepare_v26_models.py`로 새 폴더에 준비한다. 체크포인트 해시·모델 구조·입력 해상도·클래스 순서를 확인하고, 가중치만 앱 실행 형식으로 저장한다. 사이즈 모델은 18개 출력에 맞춰 아동 70을 2XS로 변환한다. 아동 숫자 60과 성인 문자 2XS는 이 모델의 자동 분류 클래스에 없다. 개별 입력은 기존 UI에서 수정할 수 있다. 모델 해시와 사이즈 클래스 순서를 캐시 지문에 포함한다.

해·달 아이콘과 테마 색상을 하나의 320ms 전환에 연결했다. 해·달 윤곽은 QML 벡터 도형으로 표시하며 회전·축소·투명도를 함께 바꾼다. 사진을 더블클릭한 뒤 마우스를 뗄 때 뒤쪽 카드가 키보드 포커스를 가져가는 문제를 수정했다. 확대창에서 Esc와 닫기 버튼은 현재 페이지와 옷 포커스를 유지한 채 검수 화면으로 돌아간다.

- 앱·QML·엑셀 관련 검사 91개 통과. 확대창의 실제 사진 더블클릭, Esc, 닫기 버튼을 포함한다.
- 실제 사진 9벌 CPU 검증에서 70·160·170·3XL·XS·M 판독과 수동 판넬 영역 경로를 확인했다.
- 프로젝트 내부 격리 설치에서 모델 파일 해시와 기존 제거 등록 정보 보존을 확인했다. 설치 실행 파일로 사진 3벌을 분석해 수동 입력 보존, 이전 분석 캐시 갱신, 아동 성별 확인 요구를 확인했다. 두 날짜를 엑셀에 순차 저장했고 첫 시트 XML은 동일했다.
- 이 검증은 개발 PC의 격리 데이터 및 소프트웨어 렌더링 환경에서 실행했다.

설치파일은 `dist-releases/v2-7f159c01b86a/CoatDesk-2.6.0-Setup.exe`에 있으며, 해당 폴더의 `build-report.json`에 모델·설치파일 해시를 기록한다.

같은 조합을 다시 빌드할 때는 CPU 환경에서 아래 명령을 실행한다. 첫 번째 명령의 출력에는 새 경로를 지정한다.

```powershell
.\.local\ai-installer-venv\Scripts\python.exe -m scripts.prepare_v26_models --candidate model-results/20261102-robust-four-models --installed-assets dist-releases/v2-8be96f4d8716/CoatDesk2/_internal/resources/ai --output .local/v26-rebuild/resources/ai
.\.local\ai-installer-venv\Scripts\python.exe scripts/build_v2.py --ai-assets .local/v26-rebuild/resources/ai --makensis .downloads/nsis-3.13/nsis-3.13/makensis.exe
```
