# 최종 보관 파일과 정리 기준

2026-11-23 · 최종 앱 2.6.4

## 사용할 파일

| 용도 | 파일 | 내용 |
|---|---|---|
| 프로그램 설치 | `설치파일/CoatDesk-2.6.4-Setup.exe` | 최신 설치파일 하나를 로컬에 유지 |
| 처음 사용하는 분 안내 | `output/pdf/CoatDesk_USER_MANUAL.pdf` | 19개 항목, 12쪽 |
| 사용자 매뉴얼 편집 | `output/docx/CoatDesk_USER_MANUAL.docx` | 위 매뉴얼의 Word 문서 |
| 기술 공부 | `output/pdf/CoatDesk_STUDY_EXPLAINED.pdf` | 22개 장, 25쪽 |
| 공부 설명서 편집 | `output/docx/CoatDesk_STUDY_EXPLAINED.docx` | 위 설명서의 Word 문서 |

소스와 문서 원문은 이 Git 저장소에 보관한다. 문서는 Microsoft Word에서 목차·페이지 번호를 갱신한 뒤 PDF로 내보냈다. 전체 페이지 이미지와 한글·표·코드·링크 배치를 확인하고, 원문 설명 블록의 누락도 대조했다. 문서 변환을 위해 앱 기능이나 모델을 추가로 바꾸지는 않았다.

## GitHub 다운로드

[2.6.4 Release](https://github.com/jiwoo0103/lovecoat/releases/tag/v2.6.4)에 최신 설치파일과 위 문서 네 개, `SHA256SUMS.txt`를 제공한다. 설치파일은 큰 바이너리이므로 Git 소스 이력에 직접 넣는 대신 Release 첨부파일로 제공한다. 앱 실행에 필요한 모델은 설치물에 포함되며, 원본 사진·전체 라벨·개인 DB·이전 인증 설정은 첨부하지 않는다.

설치파일 크기는 477,231,542바이트, SHA-256은 `7a060dee49febe25a835fad0210864c417c0fc720e90f2fb05e1cc8ef73d0ab5`다. 로컬 `output/SHA256SUMS.txt`에서도 문서와 설치파일의 지문을 확인할 수 있다.

## 사용자가 확정한 정리 범위

소스 저장소와 `.git`, 완성된 Word·PDF, 최신 설치파일 하나를 남긴다. `.local`의 학습·평가 결과와 복사 사진·특징 캐시·로그·검증 설치본, `model-results`, 이전 `dist*` 빌드, 가상환경, 내려받은 제작 도구, 임시 파일과 이전 설치파일은 삭제 대상이다. Git에 추적되지 않는 중복 모델 자산도 대상이다.

정리 전 조사에서는 약 83.5 GB, 약 35만 파일이 후보였다. 생성 중인 작업 파일 때문에 최종 삭제 수량은 달라질 수 있다. 삭제 실행 여부와 최종 회수 용량은 작업 완료 확인을 따른다. 이 문서만으로 삭제가 이미 완료됐다는 뜻은 아니다.

원본 사진·엑셀의 프로젝트 밖 위치, 실제 사용 중인 앱 설치 위치와 작업 DB, 다른 프로젝트, 전역 Git/Codex 설정은 파일 정리 대상이 아니다. 프로젝트의 Codex 채팅은 사용자의 별도 요청으로 앱의 정식 삭제 기능에서 처리하며, 이 파일 정리로 전역 대화 저장소를 직접 지우지 않는다.

학습용 원본·라벨·실험 산출물을 지우면 기존 학습을 그 상태에서 바로 재개할 수 없다. 공개 소스만 clone해도 학습 자료나 가중치가 복원되지는 않는다. 과거 문서의 로컬 실험 링크는 이력으로 남지만 정리 후 해당 파일은 없을 수 있다. 다시 개발·학습하려면 필요한 자료와 환경을 별도로 준비해야 한다.

개발용 `실행2.cmd`는 로컬 빌드 폴더를 가리킨다. 이전 빌드를 정리한 뒤에는 그 개발 실행 경로가 동작하지 않을 수 있다. 프로그램을 사용할 때는 보관한 최신 설치파일로 설치하고 시작 메뉴의 외투작업실을 실행한다.
