# 작업 관리·내보내기 사용성 개선 검증

검증일: 2026-10-29 (Asia/Seoul). 아래 소스 검사와 마지막 절의 2.5.0 설치 EXE 검증을 구분합니다.

2026-11-01 GitHub 반영 전 같은 회귀·실행기 테스트 88개를 재실행해 모두 통과했습니다(106.14초). `coatdesk_v2`와 새 사용성 테스트의 Ruff, 스테이징 변경의 `git diff --check`도 통과했습니다. 800벌 실제 AI 측정은 아래의 2026-10-29 설치본 검증 기록을 사용하며 이번 푸시 준비에서 다시 분석하지 않았습니다.

## 구현 범위

- 홈 작업 카드의 관리 메뉴에서 이름 변경·기록 백업·삭제. 삭제는 확인창을 거치며 해당 작업의 옷 기록과 로컬 내보내기 이력을 트랜잭션으로 제거합니다. 다른 작업·원본 사진·엑셀은 유지합니다.
- 탭 ×는 저장된 작업을 유지하며 탭만 닫습니다. 진행 중인 분석·저장도 계속됩니다.
- 체크박스 선택과 상단 전체 선택 해제. 입력 지우기는 확인 후 적용하며 실행 취소가 가능합니다.
- 머리 확대창은 현재 한 벌만 재분석하고 고급 메뉴는 전체 작업을 재분석합니다. 모델·가중치·전처리·확인 기준·AI 캐시 정책은 변경하지 않았습니다.
- JSON 백업은 입력·검수·AI 결과·사진 상대 경로를 저장합니다. 사진 파일·엑셀 파일·보기 설정·내보내기 이력은 포함하지 않습니다. 기존 백업을 덮어쓰지 않고 새 파일로 기록하며, 복원은 기존 작업을 유지한 새 ID로 추가합니다. 잘못된 형식과 원본 폴더 밖의 사진 경로는 거부합니다.
- 공통 SurfaceDialog/AppField/ActionButton으로 작업 만들기·엑셀·설정·확인창을 통일했습니다. 주요 창은 하단 오른쪽에 기본/주요 버튼을 나란히 표시합니다. 고급 조작을 메뉴로 묶고 중복 배치 조작을 제거했습니다.
- 엑셀 B:N을 한 번 읽어 모든 행을 비교합니다. 오류에서도 스트림을 닫고 기존 파일 교체 전 검증·기존 부품 보존·파일 변경/잠금 검사를 유지합니다.
- 미리보기 단계는 닫아 다른 작업으로 이동할 수 있습니다. 저장 시작 후 창이 닫히고 진행 상태가 표시됩니다. 저장 대상 작업의 입력만 보호하며 홈·탭·보기 설정·다른 작업 입력은 허용합니다. 같은 파일에 대한 중복 저장은 계속 차단합니다.
