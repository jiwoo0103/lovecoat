# 라이트·다크 UI 적용 — 2026-11-04

2.6.0에서는 해·달 아이콘과 팔레트를 하나의 320ms 전환으로 연결하고 사진 확대창의 Esc 복귀를 추가했다. [2.6.0 설치 검증](V26_RELEASE_20261104.md)

상태: **개발 소스 적용·검증 완료. 기존 설치본은 갱신하지 않았다.** 사용자가 보낸 6.5초 해·달 전환 영상을 확인한 뒤, 화면별 추가 시안 검토 대신 나머지 화면도 채택한 공통 스타일로 적용하라는 요청을 반영했다.

## 적용 내용

- `coatdesk_v2/qml/Theme.qml`에 라이트·다크 기본색과 호버·눌림·포커스·비활성·오류 역할을 모았다. v6 기준색을 사용하며 버튼 채움과 글자용 강조색을 구분한다. 특히 다크에서 파란 안내 글자는 더 밝은 별도 색을 사용한다.
- 홈·작업 화면 상단에 박스 없는 해·달 아이콘을 항상 표시한다. 앱 대화상자 상단에도 같은 아이콘을 제공해 창을 닫지 않고 테마를 바꾼다. 420ms 회전·축소·교차 전환과 빠른 연속 클릭의 역방향 전환을 지원한다. 처음은 라이트, 이후 `theme` 설정에 마지막 선택을 보관한다. 운영체제 전체 테마는 변경하지 않는다.
- 기존 PySide6 6.12 / Qt Quick 구조와 의존성을 유지한다. 버튼 36px, 보조 동작 32px, 버튼 라운드 6px·카드 10px·팝업/대화상자 12px, 일반 경계 1px·키보드 포커스 2px를 사용한다. 호버 전환은 기본 140ms이며 사진의 색과 밝기는 변경하지 않는다.
- 홈은 큰 새 작업 카드를 유지하고, 환영 문구·작업 배지·작업 열기 링크를 제거했다. 작업 카드 전체 클릭·내부 관리 메뉴, 날짜·사진 범위·옷 수와 여백을 유지한다. 백업·복원 진입점은 보류해 숨겼으며 저장소의 기존 백업 호환 기능과 파일을 삭제하지 않았다.
- 분석 파랑·조건부 확인 필요 노랑·상단 엑셀 저장 초록, 온전한 분석 막대 아이콘을 적용했다. 배치의 격자 수와 입력창 토글을 도구 모음에서 제거했다. 확인 대상 카드 배경·해당 값과 사유만 강조한다. 일반 입력은 가벼운 항목명/값 네 행이다.
- 카드 체크·선택 강조·개수·Ctrl/Shift 선택·일괄 입력/후보 적용/확인/지우기/ROI 적용의 UI와 선택 전용 백엔드 상태·슬롯을 제거했다. 개별 수정·확인·ROI·방향키·현재 옷 포커스는 유지한다. 과거 선택 목록은 읽지 않고 이후 보기 저장에서 제거하며 옷 데이터 마이그레이션은 하지 않는다.
- 카테고리·성별·사이즈·연령 AND 필터와 작업별 저장/복원·과거 필터 호환을 추가했다. 검색·확인 필요 필터로 결과가 없어져도 `전체 보기`로 복구할 수 있다.
- 작업 메뉴에는 엑셀로 저장·보기 설정·고급 설정·작업 관리만 남긴다. 실행 취소는 메뉴에서만 빼고 Ctrl+Z 기능을 유지한다. 사진만 보기는 보기 설정에서 전환한다.
- 홈 관리·기존 작업 목록·일반/빠른 입력·배치·분류·드롭다운·이름 변경/삭제·사진 범위·분석 기준·사진 상세/머리 확대·엑셀 미리보기/저장에 공통 테마를 적용했다. Windows 기본 파일/폴더 선택창은 운영체제 표현을 사용한다.

## 검증

- 기존 8개 모듈과 새 `tests/test_v26_design.py`, 총 **91개 검사 통과**. 대상은 `test_v2_workspace`, `test_v2_qml`, `test_v2_ui_flow`, `test_v25_usability`, `test_v24_integration`, `test_v241_scope`, `test_v26_design`, `test_v2_review`, `test_v2_excel`이다.
- 이후 빠른 입력의 선택된 확인 필요 값도 붉게 표시하도록 마무리했으며, 관련 빠른 입력·전체 격자·보기 복원 검사 2개를 다시 실행해 통과했다.
- 전환 후 안내가 이전 모드를 가리키지 않도록 해·달 툴팁/접근성 이름을 함께 연결하고 클릭 시 툴팁을 닫았다. 관련 전환·저장·대화상자 검사 1개를 다시 실행해 통과했다.
- QML 실제 로드·주요 대화상자·최소 1000×720 및 기존 고밀도 배치 검사, 테마 전환 중간값/완료/연속 클릭·재시작 저장, 대화상자 내 전환, 확인 대상 마지막 항목 해제·전체 보기, 필터 복원·옷 데이터 보존, 키보드 Ctrl+Z·탭·사진·엑셀 회귀 검사를 포함한다. 관련 QML 런타임 경고가 없었다.
- 실제 공통 테마의 주요 일반/보조/버튼/경고/확인 필요/강조 글자와 배경 조합이 양 테마에서 4.5:1 이상임을 검사했다. 모든 접근성 항목이나 전환 도중의 모든 프레임을 검증했다는 의미는 아니다.
- 수정 Python·테스트 Ruff 통과, `compileall` 통과. `python -m coatdesk_v2 --software-rendering --data-dir <격리 검증 폴더> --smoke-test <검증 PNG>`가 종료 코드 0, `ok: true`, 경고 0으로 통과했다.
- 검사는 별도 `.local/ui-implementation-20261104/` 데이터 폴더와 offscreen/software Qt 환경을 사용했다. 사용자 작업 DB·설정·사진·엑셀은 수정하지 않았다. 실제 사용자 PC의 Windows 배율·GPU·네이티브 파일 선택창 외관은 별도 확인 범위다.
