## 전체 사진 유지·소매와 기장 별도 출력 실험

## 모델과 평가 방법

`scripts/category_first_model.py`가 자료 준비와 각 학습 단계를 담당합니다. 기존 `requirements-ab.txt`의 별도 환경(torch 2.11.0+cu128, torchvision 0.26.0+cu128)을 사용했으며 앱 의존성은 바꾸지 않았습니다.

- EfficientNet-B0, ImageNet1K V1 일반 사전학습 가중치. [설치 버전 공식 문서](https://docs.pytorch.org/vision/0.26/models/generated/torchvision.models.efficientnet_b0.html).
- 일반 가중치 출처: `https://download.pytorch.org/models/efficientnet_b0_rwightman-7f5810bc.pth`. SHA-256 `7f5810bc96def8f7552d5b7e68d53c4786f81167d28291b21c0d90e1fca14934`, 21,444,401바이트. 다운로드 및 모든 실험 산출물은 로컬에 보관했습니다.
- 기존 준비 자료의 판넬 검출 상자를 1080폭 입력에서 8픽셀 여유를 두어 흰색으로 가립니다. 옷 전체를 자르지 않고 종횡비를 유지해 320×320에 여백을 맞춥니다. 사이즈 글자 자체를 입력하지 않으려는 처리입니다.
- 밝기·축소 후 여백 이동·좌우 반전으로 보강합니다. 중심 자르기나 임의 영역 자르기는 하지 않습니다.
- 3분할, 각 분할은 학습 72벌·평가 36벌입니다. 기존 `source_group`을 유지하고 동일 사진 해시의 중복도 거부합니다. 분류·성인/아동 분포를 가능한 범위에서 맞췄습니다. 미확인 유사 옷의 존재까지 배제한 것은 아닙니다.
- 각 옷은 그 옷의 그룹을 학습에 포함하지 않은 모델로 정확히 한 번 평가합니다. 기존 성별/사이즈 작업의 분할을 카테고리 분할로 재사용하지 않습니다.
- 학습 전에 프로토콜·입력 파일·소스 코드·일반 가중치 해시를 고정했습니다. 각 분할은 고정 20회, batch 12, AdamW, 특징부 학습률 0.0001·출력부 0.001, 제곱근 역빈도 클래스 가중치, label smoothing 0.02입니다. 평가 결과로 체크포인트·학습 횟수를 선택하지 않았습니다.
- 전체 108벌로 최종 실험 모델을 별도 학습했습니다. 이 모델의 학습 정답률을 평가 성능으로 보고하지 않습니다.
