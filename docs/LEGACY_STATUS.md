# 구현 상태

> **이전 버전 상태 보존본:** 현재 상태는 [PROJECT_STATUS.md](../PROJECT_STATUS.md), 재구축 요구사항은 [REBUILD_HANDOFF.md](../REBUILD_HANDOFF.md)에 정리했습니다. 아래 내용은 재구축 전 프로토타입의 기록입니다.

## 구현됨

- Windows PySide6 앱, 사진 폴더 검사, 원본 보존 복사, 코드가 포함된 이름 변경, 중복/충돌 검사.
- 사진은 원본 번호 폴더에서 바로 보기. 사진 모으기는 더보기의 내보내기로 이동하고 Google 연결 설정/도움말도 같은 메뉴에 배치.
- 상단 작업 메뉴/사진 도구 두 줄, 옷 정보·사진 인식 탭, 접는 인식 설정, 보기 설정 팝업, 입력 패널 접기, 하단 페이지·입력 현황·저장 상태.
- 날짜·사진 폴더·옷 수로 고르는 최근 작업 목록. 기존 JSON 열기 지원 및 입력/선택/보기 상태 유지.
- 시트 주소·날짜 탭·변경 미리보기·전송을 한 창으로 통합. 주소/탭 변경 시 이전 전송 계획 무효화.
- 한 벌당 3칸 / 정면 3열 보기, 1~8줄, 확대, 머리 영역 지정, 검색, 범위 선택.
- 목록 사진 크기 100~250%(기본 150%), 사진 목록에서 방향키/좌우 드래그로 페이지 이동.
- 카테고리·성별·연령·사이즈 수동/일괄 입력, 제외, 실행 취소, JSON 자동 저장과 복원.
- 새 작업 JSON은 바탕화면/외투 작업실 작업에 고유 이름으로 자동 저장. 저장 위치 질문 제거.
- 로컬 Tesseract 사이즈 제안, 등록한 머리 모양 비교, 경계 앞뒤 표시. 제안은 확인 후 적용.
- 경계 후보는 연한 주황색 배경/테두리로 강조. 선택 시 파란 테두리, 제외 시 회색 배경.
- Google OAuth 설정, 날짜 탭 선택, 기존 코드 매칭, 변경 미리보기, 필요한 셀만 쓰기,
  이미지 수식 유지/복사, 제한적인 서식 행 확장, 전송 전 변경 검사와 전송 후 확인.
- 실행 파일 빌드 스크립트, 실행.cmd, 사용 설명서.
- 최신 빌드를 바탕화면/외투 작업실 작업에 복사하는 스크립트 제공. 외투 작업실.exe와 _internal을 함께 보관하며 작업 JSON 보존.
- exe 시작 시 바탕화면 폴더와 실행 복사본 자동 준비. 원본/작업 JSON 보존, 동일 파일과 바탕화면에서 직접 실행 시 복사 생략.

## 확인한 범위

- 자동 테스트 37개와 Ruff 검사 통과.
- 제공된 13벌 / 39장 복사와 재실행, 원본 해시 불변 확인.
- 샘플 사이즈 13개: XS 1개, S 7개, M 5개 모두 육안 표기와 일치.
- 샘플 경계: 0001↔0002, 0008↔0009의 앞뒤 표시.
- 위 사진은 구현 조정에도 사용했으므로 독립적인 정확도 평가가 아님.
- 소스 실행 화면, OCR 런타임, DPAPI, Google API 정의 로드 검사 통과.
- 패키지 exe에서도 화면, OCR(XS), DPAPI 및 Google API 정의 로드 검사 통과.

## 남은 실환경 검증

- 실제 Google 계정/공유 시트가 제공되지 않음. OAuth와 실제 쓰기는 미검증이며 외부 시트 쓰기는 수행하지 않음.
- 남성·유아동 및 다른 촬영 위치/조명/사이즈의 확인된 샘플이 필요함.
- 머리 분류는 초기 모양 비교 방식. AI 이미지 분류 모델과 비교 검증하지 않음.
- 날짜 탭 생성은 사용자가 Google Sheets에서 기존 양식으로 준비해야 함.
- 고정 목록 외 유효성 검사 등 지원하지 않는 서식은 자동 변경을 중단하도록 구현됨.

원본 사진/엑셀은 수정하지 않았고, Git 초기화·커밋·푸시·배포는 하지 않았음.
