# 판넬 위치 AI

2026-10-25 사용자 요청: 성별·사이즈는 판넬 전체 추출 사진으로 고정하고, 판넬 위치만 별도 AI로 학습합니다. 기존 앱·설치파일·사진·성별·사이즈 라벨·분류 가중치는 보존합니다.

## 역할과 입력

`coatdesk_locator`는 원본 전체 사진에서 머리통 판넬의 사각형 좌표를 찾습니다. SSDLite320 MobileNetV3-Large를 배경+판넬 1종으로 추가 학습합니다. 검출기가 출력한 박스에 8% 여백을 더하고, 원본의 같은 좌표계에서 머리·귀·턱을 함께 잘라냅니다. 글자나 앞머리를 다시 작게 자르지 않습니다.

사진은 기존 분석과 같은 EXIF 방향 정리·비율 유지 1080×1920 미리보기 좌표계로 읽습니다. 위치 모델에는 사진 전체를 360×640으로 줄인 RGB를 넣고, 모델 내부에서 320×320으로 처리합니다. 결과 좌표를 1080×1920으로 되돌려 자른 뒤 기존 `panel-shape`·`panel-size` 분류기에 넣습니다. 두 분류기의 가중치와 512×512 비율 유지·여백 처리는 유지합니다.

## 박스 정답

- 기존 `coatdesk_ab`의 1,090장과 원래 역할·그룹 분할을 유지합니다. 내부 학습 516장·조건 선택 129장, 최종 학습 645장, 최종 검증 162+283=445장입니다.
- 기존 템플릿 위치 코드를 초안으로 쓰고, 얼굴 안쪽 흰 종이와 검은 윤곽으로 박스를 보정했습니다. 이 초안을 정답으로 자동 승인하지 않습니다.
- 원본 맥락과 박스를 함께 표시한 31페이지, 1,090장을 Codex가 육안 검수했습니다. 자동 보정 뒤에도 남은 0013·3021·1345·2999번의 위치/과도한 박스를 직접 수정했습니다. 일부 경계 오차에 여유를 두어 검수한 박스 바깥에 2%를 추가했습니다.
- 박스 정답·수정 이력은 기존 성별/사이즈 파일에 쓰지 않고 별도 `box-labels.json`, `review-events.json`에 저장합니다. 좌표 기준 크기와 사진 SHA-256을 기록합니다. 독립 담당자가 전수 검수한 정답은 아닙니다.
- 실제 학습 입력은 **원본 전체 RGB와 박스 좌표**입니다. 성별·연령·사이즈 필드는 위치 모델 입력이나 학습 목표로 사용하지 않습니다. 위치 학습 클래스는 모든 사진에서 판넬 1종입니다.

## 학습과 재개

기존 별도 환경 `.local/ab-venv`의 PyTorch 2.11.0+cu128·Torchvision 0.26.0+cu128을 사용합니다. 추가 패키지를 설치하지 않았습니다. 공식 일반 COCO SSDLite 초기 가중치 약 14MB만 프로젝트 내부에 내려받고 출처·SHA-256과 라이선스를 저장했습니다.

호환되는 특징·박스 회귀·중간 분류 특징 가중치를 불러오고, 출력 개수가 달라진 분류 출력은 새로 초기화합니다. 작은 판넬에 맞춰 앵커 크기 범위 0.10~0.70을 사전에 정했습니다. 배치 12, AdamW, 특징부 학습률 0.0002·출력부 0.001, 최대 내부 학습 50회를 적용합니다. 일반 모델의 BatchNorm 통계는 고정하고 학습 가능한 계수는 최적화합니다.

원본 전체의 회전 ±7도, 크기 0.78~1.22배, 이동, 좌우 반전, 밝기·대비를 보강합니다. 변환된 머리 박스 전체가 화면 안에 남는 경우에만 적용합니다. 판넬이 없는 별도 사진은 학습에 추가하지 않았고, SSD의 기본 배경 앵커 학습을 사용합니다.

내부 129장에서 점수 0.5 이상·여백 추출이 정답 박스 99% 이상을 포함하는 수를 우선하고, 동률이면 IoU 0.75 이상 수·평균 IoU로 회차를 고릅니다. 선택한 횟수만큼 **초기 COCO 가중치에서 다시 시작하여 645장 전체로 최종 학습**합니다. 최종 검증 445장은 회차 선택에 넣지 않습니다.

매 회차 종료 후 모델·최적화 상태·AMP 상태·난수 상태를 임시 파일에 쓴 뒤 `last.pt`로 원자적 교체합니다. 동일한 명령을 재실행하면 마지막 완료 회차 다음부터 이어갑니다. 완료한 단계는 재학습하지 않습니다. 코드·라벨·전처리 배열과 초기 모델 해시가 바뀌면 재개를 중단합니다.

이번 작업 경로: `.local/panel-detector-20261025`. 결과 경로: `model-results/20261025-panel-detector`.

```powershell
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_locator.train --stage inner
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_locator.train --stage final
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_locator.evaluate
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_locator.benchmark
```

`evaluate`는 이미 있는 결과 폴더를 덮어쓰지 않습니다. 다시 평가하려면 새 `--output` 경로를 지정합니다. 평가 후 `review-pages/`의 실제 AI 추출 범위를 전부 확인하고 `crop-visual-review.json`에 기록한 다음 `python -B -m coatdesk_locator.report`로 요약을 만듭니다. 평가 후 잘못된 박스를 수동 교체해서 점수를 올리지 않습니다.

새 학습 자료를 만들 때는 새 `--work`에서 `labels prepare` → 페이지별 검토와 `labels approve --pages ... --corrections ...` → `labels finalize` → `dataset.prepare_cache`를 순서대로 실행합니다. 검토되지 않은 페이지가 있으면 정답 확정을 막습니다.

## 분석 결과 확인 정책 — 앱 연결 시 반영

2026-10-26 사용자 결정: 잘못된 자동 입력보다 판단 보류를 우선하고, 판넬 위치·남성/여성/아동·사이즈의 기준을 각각 적용합니다. 현재 작업은 위치 모델 개선이며 이 UI 기능은 아직 구현하지 않습니다.

- 판넬 위치 점수가 기준 미달이면 성별·사이즈 자동 입력을 보류합니다. 원본과 보류 후보 영역도 표시하고 사용자가 영역을 확인·수정한 뒤 해당 옷을 분류할 수 있게 합니다.
- 분류 모델별 최고 점수가 기준 미달이면 해당 미입력 항목을 빈칸/확인 필요로 남기고 후보와 점수를 표시합니다. 통과한 다른 항목까지 함께 비우지 않습니다. 사람이 입력한 기존 값은 덮어쓰지 않습니다.
- 확인 필요 항목을 모아 검수할 수 있게 하고, 기존의 사람 확인 완료·필수 항목·시트 전송 게이트를 유지합니다. 점수 기준 통과와 사람의 확인 완료는 별개입니다.
- 실사용에는 정답 박스가 없으므로 IoU가 아닌 모델 출력 점수를 기준으로 씁니다. 출력 점수는 보정된 실제 정답 확률이 아닙니다. 기준값은 모델별 검증에서 오답·보류 비율을 확인하여 정합니다. 아동 남녀는 현재 모델의 학습 클래스가 아닙니다.
