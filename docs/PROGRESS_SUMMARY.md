- 실제 사진 폴더의 번호 범위·에러번호를 공통 대상으로 사용. 코드 앞자리 0 보존, 사진 경로 재연결.

## 선택한 모델과 규칙

| 단계 | 현재 선택 | 처리 |
|---|---|---|
