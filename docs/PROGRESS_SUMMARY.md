## 선택한 모델과 규칙

| 단계 | 현재 선택 | 처리 |
|---|---|---|
| 판넬 찾기 | SSDLite MobileNetV3-Large, 448 입력 | 정면에서 머리 판넬 전체를 자름 |
| 남성·여성·아동 | 판넬 입력 분류 모델 | 성인 남성 / 성인 여성 / 아동 3종 |
| 사이즈 | 별도 판넬 입력 분류 모델 | 숫자·문자 17종에서 선택, 아동 숫자는 엑셀 대응표로 변환 |

- 기본 보류 기준: 판넬 50%, 성별/연령 95%, 사이즈 95%. UI 변경·저장 코드 구현.
- 판넬이 기준 미달이면 두 분류를 실행하지 않고 사용자가 영역을 확인. 분류 점수 미달이면 해당 값만 제안하지 않음.
- 점수는 모델의 판단 강도이며 실제 정답 확률로 보정한 값이 아님.
- 아동 성별은 사용자 지시로 모두 남아라는 **임시 규칙**. 아동 남녀를 따로 학습한 모델은 아님.
- 현재는 GPU 없는 PC를 위한 CPU 실행 경로. 기존 OCR·앞머리만 보는 모델·사진 전체 입력 비교 모델은 최신 앱 선택 경로에서 사용하지 않음.
