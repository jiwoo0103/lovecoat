## 현재 상태

**앱의 주요 기능과 AI 모델 연결 코드는 있으나, 2.1 설치 후 앱이 열리지 않는 오류가 확인되어 배포를 보류합니다.**
기능 변경 사항을 먼저 모으고, 실행 오류를 포함해 수정·테스트한 뒤 설치파일을 다시 만들기로 했습니다.
이번 GitHub 등록은 소스와 진행 기록을 보존하기 위한 작업이며 앱 수정·재학습·설치파일 재생성은 하지 않습니다.

## 구현한 기능

- Python/PySide6 + QML 검수 화면, SQLite 작업공간·자동 저장·같은 PC 이어하기.
- 실제 사진 폴더의 번호 범위·에러번호를 공통 대상으로 사용. 코드 앞자리 0 보존, 사진 경로 재연결.
- 4벌/2벌 보기, 정면·3장 사진 보기, 확대·머리 영역 지정, 선택·일괄 입력·확인 완료·실행 취소.
- 제안과 수동 입력 분리. 수동 값을 덮어쓰지 않고 제안 적용 시 빈 항목만 채움. 카테고리는 수동 입력.
- 새 Google 시트 탭 전송 코드, 필수 항목·전체 확인 게이트, 전송 미리보기·이력·응답 유실 조회.
- PyInstaller 폴더 배포 + NSIS 사용자별 설치 구성. 작업 데이터와 원본 사진을 프로그램 파일에서 분리.

## 선택한 모델과 규칙

| 단계 | 현재 선택 | 처리 |
|---|---|---|
| 판넬 찾기 | SSDLite MobileNetV3-Large, 448 입력 | 정면에서 머리 판넬 전체를 자름 |
| 남성·여성·아동 | 판넬 입력 분류 모델 | 성인 남성 / 성인 여성 / 아동 3종 |
| 사이즈 | 별도 판넬 입력 분류 모델 | 숫자·문자 17종에서 선택, 아동 숫자는 엑셀 대응표로 변환 |

- 기본 보류 기준: 판넬 50%, 성별/연령 95%, 사이즈 95%. UI 변경·저장 코드 구현.
- 판넬이 기준 미달이면 두 분류를 실행하지 않고 사용자가 영역을 확인. 분류 점수 미달이면 해당 값만 제안하지 않음.
- 점수는 모델의 판단 강도이며 실제 정답 확률로 보정한 값이 아님.
- 아동 성별은 사용자 지시로 모두 남아라는 **임시 규칙**. 아동 남녀를 따로 학습한 모델은 아님.
- 현재는 GPU 없는 PC를 위한 CPU 실행 경로. 기존 OCR·앞머리만 보는 모델·사진 전체 입력 비교 모델은 최신 앱 선택 경로에서 사용하지 않음.

## 모델 실험에서 확인한 결과

- 기존 학습 645벌로 학습. 판넬/원본 전체 입력 비교 후 판넬 전체 방식 선택.
- 개선한 위치 모델 + 고정한 두 분류기의 기존 검증 924벌에서 남성/여성/아동·사이즈 동시 정답 924/924.
- 기존 2950번의 위치 점수는 46.8%에서 94.3%로 개선. 변형 입력 8,316개에서 위치 보류 24→1개.
- 같은 개발 PC의 32장 비교에서 전체 평균 약 0.330초/벌. 모델 초기 로딩·앱 저장 등을 포함한 실제 앱 처리시간 보장이 아님.
- 같은 촬영 묶음의 이미 확인한 사진을 이용한 회귀 검증이며 새 촬영일·다른 PC 성능이나 일반 정확도 100%를 보장하지 않음.
- 위 결과는 모델 평가 기록. 앱 기본 95% 보류 정책에서 실제 제안되는 건수나 설치 프로그램의 기능 검증 결과와 구분.

## 실행 문제와 검증 상태

- 기존 설치파일: `CoatDesk-2.1.0-AI-Setup.exe`, 약 436MB. 빌드는 성공했지만 사용자 보고상 설치 후 실행되지 않음.
- 재현: `tests/test_v2_qml.py` 2개 실패. `Main.qml:284~286`에서 `Unexpected token ';'`; 최상위 화면이 생성되지 않음.
- **아직 수정하지 않았으며** 다른 문제가 추가로 있는지는 최종 수정 후 검사해야 함.
- 최초 설치파일 생성 시에는 오전 8시 10분 이후 테스트를 생략하라는 지시가 있었음. 이후 오류 조사에서 위 실패를 재현함.
- 과거 2.0의 테스트·설치 검증 성공 기록은 2.1의 성공을 뜻하지 않음.
- 실제 담당자 Google 로그인·온라인 전송, 별도 깨끗한 Windows PC 설치·실행·AI 분석은 미검증.
