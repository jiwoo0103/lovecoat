# UI 개선 요구사항 및 구현 계획

최초 기록일: 2026-11-02. 최신 인계: 2026-11-03. 모델 학습 비교는 끝났으며 사용자는 새 판넬·성별/연령·사이즈 전환과 이 UI 요구사항을 다음 작업으로 인계하도록 요청했다. **본 앱의 아래 UI 계획은 아직 미구현**이다. 독립 HTML 라벨링 화면을 한 화면에 맞춘 작업과 구분한다. 최신 승인 범위·작업 순서는 [다음 세션 인계](NEXT_SESSION_HANDOFF_20261103.md)를 따른다. 카테고리 라벨링/재학습은 나중이며 설치파일은 빌드하지 않는다.

## 확정 요구사항

1. 하단 작업 탭과 닫기 아이콘을 간결하게 개선한다. 활성 작업은 분명하게 구분하고 탭 닫기는 작업 기록 삭제와 구분한다.
2. 분류 메뉴에 옷 카테고리 필터를 추가한다. 전체/자켓/코트/조끼/기타를 제공하며 성별·사이즈·성인/아동 조건과 함께 적용한다.
3. 옷 선택 기능과 그에 의존하는 기능을 모두 제거한다. 옷별 입력·확인·사진 확대·개별 판넬 영역 수정은 유지한다.
4. 카테고리의 소매·기장 판단은 유지한다. 소매가 없고 긴 옷은 기타 및 확인 필요로 남기고 사용자가 최종 분류한다. 재학습도 이 운영 규칙을 유지한다.

## 구현 방향

- 기존 PySide6/QML을 유지한다. Fluent 2 탭 디자인을 참고해 비활성 탭의 배경·테두리를 줄이고 활성 탭에 강조색을 사용한다. 닫기는 별도 네모 버튼 대신 탭 안의 작은 아이콘으로 표현하되 클릭 영역과 키보드 접근성을 확보한다. 긴 작업명은 생략하고 가로 스크롤을 유지한다. 홈·작업 추가·작업 기록 보존 및 기존 탭 전환 동작은 유지한다.
- `Main.qml`의 분류 팝업에 카테고리를 추가하고 필터 전달 인자를 확장한다. 백엔드의 필터 상태·AND 조건 검색·저장/복원·초기화를 함께 변경한다. 과거 저장값에 카테고리가 없으면 전체로 취급한다.
- 체크박스·선택 테두리·선택 개수·선택/해제·Ctrl/Shift 범위 선택을 제거한다. 선택한 옷 일괄 입력·후보 적용·확인·입력 지우기·판넬 영역 일괄 적용의 UI와 선택 전용 백엔드 메서드 및 상태도 제거한다.
- `GarmentCard.qml`/`PhotoPane.qml`의 사진 동작에서 다중 선택을 분리하고, 개별 편집·상세 창에 필요한 현재 옷 포커스를 유지한다. 작업 탭 전환·드롭다운·파일 대화상자의 선택 동작은 옷 다중 선택 제거 대상이 아니다.
- 과거 보기 상태의 선택 목록은 무시한다. 옷 입력값·확인 상태·작업 기록을 지우는 데이터 마이그레이션은 수행하지 않는다.
- 긴 민소매는 기타/확인 필요를 유지하고 낮은 점수의 다른 카테고리 후보 선입력도 유지한다. 엑셀의 실제 정답을 이 예외 처리 때문에 기타로 덮어쓰지 않는다.

## 검증

- 카테고리 단독 및 다른 조건과의 AND 검색, 초기화, 작업 전환과 재시작 후 필터 복원, 기존 저장값 호환을 검증한다.
- 선택 관련 컨트롤·상태·호출이 남지 않았는지 검사하고 기존 선택 테스트를 정리한다. 옷별 수정·확인·실행 취소·사진 확대·개별 판넬 수정·페이지 이동·분석을 회귀 검증한다.
- 탭 활성/비활성/호버/포커스, 긴 이름과 많은 탭, 닫기와 인접 탭 전환, 마지막 탭 닫기 후 홈 이동 및 기록 보존을 실제 QML에서 확인한다.
- 소매 없음+긴 기장이 기타/확인 필요로 남는지 테스트한다. 설치파일 생성·사용자 DB 직접 변경은 수행하지 않는다. 새 판넬·성별/연령·사이즈 채택은 최신 인계 문서에 기록된 별도 연결 작업이며 아직 실제 적용하지 않았다. 카테고리 모델 교체로 확대하지 않는다.
