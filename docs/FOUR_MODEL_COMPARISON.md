# 판넬 전체와 원본 전체: 새 모델 4개 비교

2026-10-24 사용자 요청에 따른 별도 실험입니다. 이전 `coatdesk_ml` 모델은 이번 학습·비교에서 사용하지 않습니다. 원본 사진, 기존 라벨, 앱과 설치파일은 변경하지 않습니다.

## 비교 조건

| 모델 | 입력 | 출력 |
|---|---|---|
| `panel-shape` | 자동으로 찾은 머리·귀·턱·얼굴 글자를 포함한 판넬 전체 | 성인 남성 / 성인 여성 / 아동 |
| `panel-size` | 위와 같은 판넬 전체 | 기존 사이즈 표기 17개 중 하나 |
| `whole-shape` | 정면 원본 사진 전체 | 성인 남성 / 성인 여성 / 아동 |
| `whole-size` | 정면 원본 사진 전체 | 기존 사이즈 표기 17개 중 하나 |

네 모델은 각각 별도로 최적화한 가중치를 가집니다. 두 작업을 한 모델의 출력만 바꿔 실행하거나 이전 외투 모델에 입력만 바꾸는 실험이 아닙니다. 공정한 초기 조건을 위해 같은 작업의 두 입력 방식은 같은 일반 ImageNet 초기 가중치에서 시작합니다.

원본 방식은 내용이 잘리지 않도록 비율을 유지해 축소하고 흰 여백을 더해 512×512로 만듭니다. 중앙 자르기, 임의 영역 자르기, 좌우 반전은 하지 않습니다. 판넬 방식도 글자나 앞머리를 다시 작게 자르지 않고 판넬 전체를 같은 크기로 변환합니다. 따라서 이 비교는 같은 네트워크 입력 크기와 학습 예산에서의 비교이며, 원본의 모든 해상도를 그대로 처리하는 실험은 아닙니다.

## 자료와 분할

- 기존 807벌: 학습 645벌, 이전 검증 162벌. 학습 645벌 안에서 516/129벌로 학습 횟수를 선택합니다.
- 추가 성인 283벌: 학습에 사용하지 않고 이전 검증 162벌과 구분해 평가합니다. 이 자료는 초반 0001~1108번과 중복 후보를 제외해 만들었던 기존 추가 검증 자료입니다.
- 최종 네 모델 모두 학습 645벌, 평가 445벌입니다. 정면 사진만 사용합니다.
- 기존 중복 후보 그룹 분할을 유지합니다. 1,090벌의 그룹 952개와 동일 파일 해시가 분할 사이에 겹치지 않는지 검사했습니다. 사진이 다른 같은 실물 옷까지 완전히 분리했다는 보장은 아닙니다.
- 라벨은 기존 사용자 확인 기준에 따른 AI 판독입니다. 독립 담당자가 전부 다시 라벨링한 자료가 아닙니다. 추가 자료의 1407번은 이전 검증 때 정정한 라벨을 그대로 사용합니다.
- 아동 139벌의 남아 지정은 사용자 임시 규칙입니다. 이번 모델이 학습하는 클래스는 **아동**이며 아동 남녀 구분을 학습하지 않습니다.

사이즈 클래스는 `80, 90, 100, 110, 120, 130, 140, 150, 160, 170, XS, S, M, L, XL, 2XL, 3XL`입니다. 글자를 자유롭게 읽는 OCR이 아니라 이 17개 중 선택하는 분류기입니다. 성인 2XS·아동 60/70 자료가 없으며 아동 170은 전체 2벌뿐입니다. 추가 283벌에는 아동·3XL 새 표본이 없습니다.

## 위치 찾기와 학습

판넬 위치는 내부 학습용 0039·0001·1185번에서 얻은 전체 윤곽 기준으로 찾습니다. 얼굴 중앙 글자는 위치 비교에서 제외하고, 여러 크기와 각도를 비교한 뒤 머리 둘레에 여백을 더합니다. 옷을 머리로 오인하지 않도록 얼굴 안쪽의 흰 종이 비율도 검사합니다. 위치 점수 통과는 정확히 잘랐다는 보장이 아니므로 검증 사진의 실제 입력도 결과에 남깁니다. 이 위치 찾기는 학습된 검출 모델이 아니라 고정된 템플릿 알고리즘입니다.

위치 찾기는 내부 학습 사진만 보고 점검·수정한 뒤 고정했습니다. 네 모델의 학습이 전부 끝나기 전에는 이번 최종 검증 예측을 열지 않습니다. 결과를 본 뒤 위치 규칙, 라벨, 학습 횟수나 가중치를 재조정하지 않습니다.

분류기는 ImageNet ResNet18, 출력 간격 16, 학습 가능한 공간 가중 평균과 작업별 단일 출력으로 구성합니다. 배치 12, AdamW, 특징부 학습률 0.0001·출력부 0.001, 클래스 빈도 보정, label smoothing 0.02, 최대 24회 학습을 적용합니다. 내부 검증 정답 수와 손실로 횟수를 고른 뒤 645벌 전체로 처음부터 다시 학습합니다. 밝기와 전체 축소·여백 이동만 보강하고 글자나 머리 일부를 제거하지 않습니다. 같은 사진 안의 글자와 옷을 모델이 함께 볼 수 있으므로, 가림 진단도 별도로 기록합니다.

학습 설정·데이터·핵심 코드 해시는 학습 전에 `train-protocol.json`에 고정합니다. GPU 실행 오류가 발생한 첫 시도의 로그는 보존하고, 같은 조건에서 각 단계를 별도 프로세스로 실행합니다. 완료된 단계만 재사용하며 실패한 부분 가중치를 최종 모델에 이어 붙이지 않습니다.

## 실행과 산출물

앱용 `.venv`와 별개인 `.local/ab-venv`에 `requirements-ab.txt`의 버전을 설치합니다. 이 실험은 RTX 3060/CUDA 12.8을 사용하며 앱 실행에 이 환경이 필요한 것은 아닙니다. 일반 초기 가중치 출처·SHA-256·라이선스는 `.local/ab-assets`와 결과 폴더에 기록합니다. 사진 외부 업로드나 유료 API는 사용하지 않습니다.

이번 고정된 작업의 단계별 재개 명령:

```powershell
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_ab.orchestrate --work .local/ab-work-20261024-r3
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_ab.evaluate --work .local/ab-work-20261024-r3
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_ab.benchmark --work .local/ab-work-20261024-r3
.\.local\ab-venv\Scripts\python.exe -B -m coatdesk_ab.report
```

이미 완료된 평가 폴더는 덮어쓰지 않습니다. 평가·성능 측정을 다시 실행할 때는 새 `--output`을 지정합니다. `coatdesk_ab/runner.py`는 최초 설정과 단일 프로세스 실행 기록이며 이번 재개는 `orchestrate.py`를 사용했습니다.

결과는 [RESULTS.md](../model-results/20261024-four-model-comparison/RESULTS.md), 사진별 비교는 [비교보기.html](../model-results/20261024-four-model-comparison/비교보기.html)에 기록합니다. 모델 4개는 `models/*.pt`, 모델별 설정은 `models/*.json`, 예측·원시 softmax 점수는 `*-predictions.json/csv`에 저장합니다. 원시 점수는 보정된 신뢰 확률이 아닙니다.

`benchmark.json`은 원본 읽기·축소·두 모델 추론과 판넬 방식의 위치 찾기를 포함한 32장 측정입니다. 모델/런타임 시작 시간은 제외합니다. GPU FP16과 CPU FP32를 구분하고 일괄 추론 결과와의 차이도 기록합니다. `diagnostics.json`은 얼굴 중앙·배경·판넬 전체를 각각 흰색으로 가리는 후속 진단입니다. 얼굴 중앙은 기하학적 직사각형이며 글자만 정확히 지운 마스크가 아니므로 인과관계나 일반 정확도의 증명으로 취급하지 않습니다.

이번 결과는 같은 촬영 자료, 한 분할, 한 시드의 비교입니다. 이전에도 검토한 검증 자료이므로 완전히 새로운 촬영일의 독립 시험이 아닙니다. 새 모델을 앱에 연결하거나 설치파일을 다시 배포하는 작업은 포함하지 않습니다.
