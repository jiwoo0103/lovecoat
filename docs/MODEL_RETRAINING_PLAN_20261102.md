## 1. 반복 촬영 제거 및 정답 보완

- 사용자가 약 1,000벌의 반복 촬영이 있다고 알렸다. 1,000을 기계적으로 빼거나 코드 범위만으로 제거하지 않는다. 기존 중복 그룹, 원본 파일 해시, 판넬을 제외한 몸통 유사 해시로 후보를 찾고 사진을 대조한다. 유사 해시는 후보 탐색용이며 서로 다른 검정 옷 등을 자동 병합하는 근거로 쓰지 않는다.
- 같은 옷의 반복 촬영으로 확인되면 대표 사진 한 장을 남긴다. 판넬·소매·밑단이 온전히 보이고 초점이 선명한 사진을 우선하며 동률이면 해상도, 코드 순으로 선택한다. 모호한 중복 후보는 확인 전까지 평가 세트에 분산하지 않는다. 원본은 삭제하지 않고 제외 코드·대표 코드·근거를 기록한다.
- 동일 옷인데 판넬의 실제 숫자/모양이 다른 경우는 별도로 표시한다. 카테고리는 한 장만 사용하고 판넬 관련 모델은 서로 다른 실제 판넬 표기별 한 장까지만 사용한다. 이 경우도 같은 옷 전체가 하나의 분할에만 속한다. 변형을 포함한 동일 표본의 반복 수로 클래스 분포나 평가 표본 수를 부풀리지 않는다.
- 엑셀의 카테고리·성별·연령·변환 사이즈를 업무 정답으로 유지한다. 아동 사이즈의 원문 숫자는 사진을 보고 보완하고 변환표와 일치하는지 검사한다. 새 아동 239개는 기존 원문 라벨과 대조·보완이 필요하며 70 표본도 같은 목록에 기록한다. 판독이 애매하면 추정 정답으로 학습하지 않는다.
- 판넬 위치는 기존 검수 박스를 재사용하고 대표 사진 중 박스가 없는 것만 예측 초안을 만든 뒤 실제 사진과 대조·수정한다. 중복 제거 전 현재 엑셀과 연결되는 기존 박스는 1,492개이며 나머지는 2,104개다. 중복 정리 후 실제 추가 작업 수를 다시 계산한다. 모델 예측 자체를 정답으로 승인하지 않는다.
- 카테고리는 기존 승인 소매·기장 라벨을 재사용하되 최신 엑셀과 충돌하면 재검토한다. 새 사진은 소매 유무와 기장을 별도 확인한다. 자켓/코트 이름만으로 기장을 강제 생성하지 않는다. 기장 경계·불명확 표본은 기장 손실에서 제외하고, 소매가 명확하면 소매 학습에는 사용할 수 있다. 1495번처럼 밑단이 잘린 사진은 카테고리 학습·주 평가에서 제외하고 별도 진단으로 보존한다.

## 2. 데이터 분할

- 중복 정리 후 남은 서로 다른 옷을 기준으로 학습 약 70%, 개발 검증 약 15%, 최종 평가 약 15%를 목표로 한다. 준비 단계에서 대표 코드 목록과 모델별 실제 사용 수·클래스별 수를 고정하고, 학습 전에 보고한다. 현재 3,596행에 이 비율을 바로 적용한 숫자를 확정 수량으로 사용하지 않는다.
- 네 모델에 공통 옷 그룹 분할을 사용한다. 같은 옷의 재촬영·옆/뒤 사진·모든 변형본은 서로 다른 세트로 나누지 않는다. 성별/연령·원문 사이즈·카테고리와 촬영일 분포를 고려해 배분한다. 원본을 먼저 분리하고 증강은 그 뒤에 수행한다.
- 기존 네 모델이 가중치 학습에 사용한 옷과 같은 그룹은 새 최종 평가에 넣지 않는다. 과거 개발 검증·오류 분석에 사용한 자료도 이력을 표시하고, 최종 평가에는 가능한 한 기존 학습·선택에 쓰이지 않은 옷을 우선한다. 그룹 제약이 비율보다 우선이며 고정 seed는 20261102로 한다.
- 70 표본은 독립 옷 7개가 확인되면 학습 5·개발 1·최종 1개를 목표로 한다. 같은 옷이면 그룹을 쪼개지 않는다. 원문 표기가 한 그룹뿐이면 학습 전용으로 남기고 독립 평가 불가라고 보고한다. 170 등 희소 표기에도 같은 규칙을 적용한다. 70의 9조건 결과를 서로 다른 9벌의 성적으로 계산하지 않는다.

## 3. 학습 방식 및 변경 인터페이스

- 기존 네 모델을 초기값으로 추가 학습하고 원본 가중치는 변경하지 않는다. 구조와 입력 크기는 판넬 SSDLite 448, 성별/연령 ResNet18 512, 사이즈 ResNet18 512, 카테고리 EfficientNet-B0 320을 유지한다. 카테고리의 판넬 가림과 전체 사진 비율 보존을 유지한다.
- 사이즈 모델은 실제 원문 `70`을 추가해 기존 17출력에서 18출력으로 확장한다. 기존 출력 가중치는 클래스 이름으로 복사하고 70 출력만 새로 초기화한다. 체크포인트의 클래스 순서와 대응표를 함께 저장하고 평가기는 이를 읽는다. 자료가 없는 아동 60·성인 2XS는 이번 지원 및 검증 범위에서 제외한다. 이를 거부할 수 있는 미지 클래스 탐지 능력이 생겼다고 주장하지 않는다.
- 성별/연령 모델은 성인 남성·성인 여성·아동의 기존 3출력을 유지한다. 아동 남녀는 이번 학습 대상이 아니며 사용자 필수 확인을 유지한다.
- 카테고리는 소매 유무·기장의 두 출력을 유지한다. 소매 없음+긴 기장은 기타/필수 확인으로 처리한다. 낮은 점수의 일반 후보는 선입력하되 확인 필요 상태를 유지한다. 긴 민소매의 엑셀 정답을 기타로 덮어쓰지 않고 업무 정답 일치와 예외 보류 동작을 따로 평가한다.
- 학습 증강은 승인된 예시 범위에서 원본 25%, 변형 75%로 한다. 변형 때 밝기 0.8~1.2, 따뜻함/차가움 RGB 배율의 원본~승인값 사이, 대비 0.85~1.0, 좌/우 완만한 음영 최대 25%, 1080px 폭 기준 Gaussian sigma 최대 0.65 중 한 종류와 강도를 매번 무작위 선택한다. 뒤집기·큰 회전·숫자 재생성·신체/밑단 자르기·복합 과다 변형은 사용하지 않는다. 정답과 위치 좌표는 보존한다.
- 모델별 독립 최적화기를 사용한다. AdamW·cosine decay·weight decay 1e-4를 사용하고 기존 코드 설정을 유지한다. 최대 회차는 판넬 40, 성별/사이즈 각 24, 카테고리 20이며 batch는 12(카테고리 16)이다. 판넬 학습률 backbone 2e-4/head 1e-3, 다른 모델 backbone 1e-4/head 1e-3, 분류 label smoothing 0.02·제곱근 역빈도 가중치·BatchNorm 고정을 기본으로 한다. class weight는 학습 세트에서만 계산한다.
- 매 회차 재개 체크포인트와 난수/최적화기 상태를 저장한다. 개발 세트에서 원본 성능을 우선하고 동률이면 9조건 성능·이른 회차 순으로 선택한다. 실행 구현에서는 원본과 9조건 정답 일치가 같을 때 확률 확신만 커진 회차로 바꾸지 않도록 이른 회차를 보존한다. 손실은 학습 진행 기록용으로 남기며 회차 선택의 추가 동률 기준으로 사용하지 않는다. 판넬은 추출 영역 보존/검출, 성별·사이즈는 원문 macro-F1와 정확도, 카테고리는 소매·명확한 기장 균형 정확도 및 엑셀 엄격 일치를 함께 기록한다. 최종 평가를 본 뒤 회차를 다시 선택하지 않는다.
- 학습/평가 준비물은 새 `.local` 실험 폴더, 최종 후보와 보고서는 새 `model-results` 폴더에 저장한다. 현행 앱의 모델 로딩 계약과 설치 경로는 이번 단계에서 바꾸지 않는다. 확장 사이즈 체크포인트는 전용 평가기에서 검증하며 앱 연결은 채택 결정 후 별도 작업이다.

## 4. 비교 실험 및 수락 기준

- 개발·최종 평가 모두 원본과 승인된 고정 8변형의 총 9조건을 사용한다. 원본 성적, 조건별 성적, 9조건 모두 맞힌 독립 옷 수를 분리한다. 원본 N벌이 9N벌의 독립 데이터가 되었다고 표현하지 않는다.
- 기존/신규 모델을 동일 코드·동일 변형에서 비교한다. 판넬은 IoU·기준 박스 포함률·보류·잘못 추출한 사례, 성별/연령과 사이즈는 클래스별 원문 및 변환값 정확도·혼동표, 카테고리는 엄격 일치·소매/기장 성능·조끼 혼동·긴 민소매 보류 누락을 기록한다.
- 정답 판넬을 넣은 분류기 단독 평가와 실제 판넬 검출부터 실행한 전체 경로 평가를 구분한다. 검출·마스킹·분석 실패를 성공 표본의 분모에서 몰래 제외하지 않는다. 기존 모델 조합·신규 전체 조합을 비교하고 개발 결과로 정한 혼합 조합이 있으면 이를 최종 평가 전에 고정한다.
- 확인 기준은 우선 기존 90% 조합으로 비교한다. 개발 세트에서 판넬·성별/연령·사이즈 기준만 50~99% 1%p 간격으로 검사하고, 카테고리 90%와 필수 사람 확인 예외를 유지한 상태에서 관찰된 자동 오분류 0건을 만족하는 자동 처리 수 최대 조합을 후보로 정한다. 자동 처리 수 동률이면 더 높은 기준을 택한다. 탐색으로 정답 후보가 바뀌는 것이 아니라 확인 필요 여부만 바뀌는지 검사한다.
- 기준과 모델을 고정한 후 최종 평가를 한 번 수행하고 실제 CPU 경로에서 확인한다. 기준을 낮춘 결과 자동 오분류가 생기면 채택 실패로 보고하며 같은 최종 평가로 기준을 다시 맞추지 않는다. 결과는 0건/실제 자동 처리 수로 보고하고 일반적인 무오류 보장으로 설명하지 않는다.
- 채택 후보는 원본의 기존 지원 클래스에서 성별·사이즈·카테고리 성능 및 판넬 영역 보존이 기존보다 나빠지지 않고, 조명 9조건 안정성이 개선되는 것을 목표로 한다. 70→170/2XL 오류의 개선과 기존 170/2XL 회귀를 별도로 검사한다. 희소 클래스는 표본 수와 평가 불가 범위를 명시한다. 개선이 없거나 퇴행한 모델은 기존 모델 유지로 제안한다.
- 관련 데이터 분리/해시/좌표/클래스 순서/출력 복사/라벨 변환 테스트, 긴 민소매 보류·낮은 점수 후보 선입력 회귀 검사, 내보낸 후보 재로딩 및 CPU 실측을 수행한다. 사진·엑셀·기존 가중치의 전후 해시와 사용자 DB 미변경을 확인한다. 비교 보고 전 설치본 교체·설치파일 빌드·외부 업로드·커밋·푸시는 수행하지 않는다.
