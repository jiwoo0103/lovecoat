# 외투작업실 사용자 매뉴얼

Windows용 2.6.4 기준 · 처음 사용하는 분을 위한 안내

외투작업실은 **옷 사진을 불러오고 → 자동 분석하고 → 사람이 확인·수정하고 → 엑셀로 저장**하는 프로그램입니다. 이 네 단계만 순서대로 하면 처음에도 사용할 수 있습니다. 입력한 내용은 자동으로 저장됩니다.

처음에는 사진이 몇 벌만 들어 있는 연습용 폴더로 순서를 익힌 뒤 실제 작업을 시작해 보세요. 프로그램에서 작업을 삭제해도 원본 사진과 이미 저장한 엑셀 파일은 지우지 않습니다.

## 1. 처음에는 이 순서대로 하세요

1. 프로그램을 설치하고 **외투작업실**을 실행합니다.
2. 홈에서 **새 작업 만들기**를 누릅니다.
3. 작업 이름·촬영일·사진 폴더·시작 번호·끝 번호를 입력하고 **작업 시작**을 누릅니다.
4. 사진이 나오면 **분석**을 누릅니다.
5. **확인 필요**를 눌러 표시된 옷을 보고, 틀린 값은 고친 다음 **확인**을 누릅니다. 빈 입력칸도 채웁니다.
6. 위쪽 **엑셀로 저장**을 눌러 파일을 고르고 **미리보기 → 새 시트에 저장**을 누릅니다.

한 번 작업을 만들고 나면 다음에는 홈의 기존 작업 카드를 열어 이어 하면 됩니다. 같은 작업을 이어 할 때 새 작업을 다시 만들 필요는 없습니다.

## 2. 설치하고 실행하기

설치파일 이름은 `CoatDesk-2.6.4-Setup.exe`입니다. 이 파일을 실행하고 설치 안내에 따라 진행하세요. 설치가 끝나면 시작 메뉴에서 **외투작업실**을 찾아 실행합니다. 바탕화면 바로가기는 설치할 때 선택할 수 있습니다.

이전 버전을 쓰고 있다면 먼저 외투작업실을 종료한 뒤 새 설치파일을 실행하세요. 프로그램 업데이트와 작업 삭제는 서로 다릅니다. 업데이트한다고 작업 기록을 삭제할 필요는 없습니다.

화면이 제대로 보이지 않으면 시작 메뉴의 **외투작업실 → 호환 모드**로 실행해 보세요. 일반 실행과 같은 작업 기록을 사용합니다.

사진 분석과 엑셀 저장에는 인터넷 연결이나 Google 로그인이 필요하지 않습니다. Python이나 GPU 프로그램도 따로 설치하지 않아도 됩니다. 엑셀 파일을 만드는 데 Microsoft Excel 설치가 꼭 필요한 것은 아니지만, 저장한 파일을 직접 열어 보려면 엑셀을 볼 수 있는 프로그램이 필요합니다.

## 3. 사진 폴더 준비하기

사진은 옷 번호별 폴더 안에 있어야 합니다. 예를 들어 1번과 2번 옷이 있다면 다음과 같은 구조입니다.

```text
사진 상위 폴더
  0_0001
    img_0_0_0.jpg
    img_0_0_1.jpg
    img_0_0_2.jpg
  0_0002
    img_0_0_0.jpg
    img_0_0_1.jpg
    img_0_0_2.jpg
```

사진 폴더를 선택할 때는 `0_0001` 하나를 고르는 것이 아니라 **번호 폴더들이 함께 들어 있는 상위 폴더**를 고릅니다. `img_0_0_0.jpg`는 기본 정면 사진이며, 나머지는 다른 각도 사진입니다.

프로그램은 원본 사진을 읽어서 보여 줍니다. 옷 분류를 수정해도 원본 사진 파일은 바뀌지 않습니다. 사진을 다른 위치로 옮겼다면 나중에 **사진 폴더 다시 연결**을 해야 할 수 있습니다.

## 4. 새 작업 만들기

홈의 **새 작업 만들기**를 누른 뒤 아래 항목을 입력합니다.

| 입력 항목 | 무엇을 입력하나요 | 예시 |
|---|---|---|
| 작업 이름 | 나중에 알아보기 쉬운 이름 | 11월 23일 오전 작업 |
| 촬영일 | 사진을 찍은 날짜 | 2026-11-23 |
| 사진 폴더 | 번호 폴더들이 들어 있는 상위 폴더 | 사진 폴더의 찾기 버튼으로 선택 |
| 시작 번호 | 이번에 처리할 첫 옷 번호 | 1 |
| 끝 번호 | 이번에 처리할 마지막 옷 번호 | 100 |
| 에러번호 | 이번 작업에서 빼려는 번호 | 12, 35 |

에러번호가 없다면 비워 둡니다. 여러 번호는 쉼표나 공백으로 나누어 쓰세요. 예를 들어 1~100번 중 12번과 35번을 빼려면 `12, 35`라고 입력합니다. 작업 범위 밖의 번호를 쓰면 안내가 나오므로 번호를 확인해 주세요.

작업 이름을 `20261123`처럼 날짜로 적으면 촬영일을 제안합니다. 촬영일은 직접 확인하고 원하는 날짜로 바꿀 수 있습니다. 촬영일은 나중에 엑셀의 새 시트 이름을 정할 때도 사용됩니다.

모두 입력했다면 **작업 시작**을 누릅니다. 사진이 안 나오면 먼저 선택한 상위 폴더와 시작·끝 번호가 맞는지 확인하세요.

## 5. 화면에서 버튼 찾기

| 위치 또는 버튼 | 하는 일 |
|---|---|
| 홈 | 만들어 둔 작업을 고르거나 새 작업을 만듭니다. |
| 위쪽 작업 이름 | 지금 어느 작업을 보고 있는지 보여 줍니다. |
| 분석 | 사진에서 분류 후보를 채웁니다. 분석 중에는 분석 중단으로 바뀝니다. |
| 확인 필요 | 사람이 확인해야 하는 옷만 모아 봅니다. |
| 배치 | 한 화면에 몇 벌씩 볼지 바꿉니다. |
| 옷 번호 검색 | 보고 싶은 번호를 찾습니다. |
| 분류 | 자켓·코트, 성별, 사이즈 등의 조건으로 골라 봅니다. |
| 엑셀로 저장 | 현재 작업을 엑셀의 새 시트로 저장합니다. |
| 위쪽 점 세 개 | 보기 설정·고급 설정·작업 관리를 엽니다. |
| 아래쪽 홈과 작업 탭 | 홈이나 다른 작업으로 이동합니다. |
| 해 또는 달 아이콘 | 밝은 화면과 어두운 화면을 바꿉니다. |

아래쪽 작업 탭의 **×**는 탭만 닫습니다. 작업 기록을 지우는 버튼이 아니므로, 닫은 작업은 홈에서 다시 열 수 있습니다.

## 6. 사진 자동 분석하기

작업을 연 다음 **분석**을 누르세요. 현재 화면의 옷부터 먼저 처리하며, 완료된 옷부터 값이 채워집니다. 사진이 많으면 시간이 걸리므로 아래쪽 진행 안내를 확인하면서 기다립니다.

자동 분석은 옷 분류·사이즈·성별·연령의 후보를 넣어 줍니다. 결과가 반드시 정답인 것은 아니므로 사진과 함께 확인하세요. 사진이 흐리거나 안내판이 가려졌다면 직접 수정하거나 다시 분석할 수 있습니다.

분석을 멈추려면 **분석 중단**을 누릅니다. 지금 처리 중인 한 벌을 마친 뒤 멈추며, 이미 끝난 결과는 남습니다. 다시 **분석**을 누르면 그대로 사용할 수 있는 완료 결과를 재사용합니다.

분석 중에도 홈이나 다른 작업으로 이동할 수 있습니다. 결과는 분석을 시작한 작업에 저장됩니다. 다른 작업을 보고 있더라도 **분석 중단**을 누르면 진행 중인 분석을 멈춥니다. 분석은 한 번에 한 작업씩 실행합니다.

사진 범위나 분석 기준을 바꾸거나 엑셀로 저장하려면 분석을 마치거나 중단한 뒤 진행하세요.

## 7. 확인 필요 표시 처리하기

빨간 테두리나 빨간 입력값은 **사람이 확인해야 할 항목이 있다**는 뜻입니다. 무조건 틀렸다는 뜻은 아닙니다.

1. **확인 필요**를 눌러 해당 옷을 모아 봅니다.
2. 사진과 옷 분류·사이즈·성별·연령을 비교합니다.
3. 잘못된 값이 있으면 원하는 값으로 바꿉니다. 빈칸이 있으면 채웁니다.
4. 모두 맞는지 본 다음 그 옷의 **확인**을 누릅니다.

후보가 맞으면 다시 고를 필요 없이 **확인**만 눌러도 됩니다. 확인이 필요한 옷은 값을 수정한 것만으로 확인이 끝나지 않을 수 있으니 마지막에 확인 버튼까지 눌러 주세요.

아동 성별은 꼭 직접 봐 주세요. 프로그램은 아동을 우선 **남성**으로 입력하므로 여아는 **여성**으로 바꾼 뒤 확인합니다. 아동 남녀를 자동으로 구분해 주는 기능은 아닙니다.

확인을 마친 뒤 값을 다시 바꾸면 재확인이 필요할 수 있습니다. 확인 표시가 없는 정상 옷은 네 항목이 모두 올바르게 채워져 있다면 별도 확인 버튼을 누르지 않아도 저장할 수 있습니다.

## 8. 분류값 직접 수정하기

옷 사진 옆의 입력칸을 눌러 원하는 값을 선택하세요. 수정한 내용은 자동으로 저장됩니다.

| 항목 | 선택할 값 |
|---|---|
| 옷 분류 | 자켓, 코트, 조끼, 기타 |
| 사이즈 | 2XS, XS, S, M, L, XL, 2XL, 3XL |
| 성별 | 남성, 여성 |
| 연령 | 성인, 유아동 |

잘못 고른 직후에는 **Ctrl+Z**로 입력과 검수 상태를 되돌릴 수 있습니다. 이미 저장한 엑셀 파일까지 되돌리는 기능은 아닙니다.

다시 분석하더라도 기존 입력값을 무조건 새 값으로 바꾸지는 않습니다. 재분석 후에도 입력란이 예전 값이라면 사진과 후보를 보고 직접 바꿔 주세요.

### 아동 숫자와 입력 사이즈가 다를 때

아동 사진의 숫자는 아래 표에 따라 문자 사이즈로 저장합니다. 사진에 60이 있고 입력칸에 2XS가 나온다면 정상적인 변환입니다.

| 사진의 아동 숫자 | 입력칸과 엑셀에 저장할 사이즈 |
|---|---|
| 60 또는 70 | 2XS |
| 80 또는 90 | XS |
| 100 또는 110 | S |
| 120 또는 130 | M |
| 140 또는 150 | L |
| 160 | XL |
| 170 | 2XL |

### 기타로 직접 고를 때

지퍼나 단추가 없다는 이유만으로 기타를 고르지는 않습니다. 앞 전체가 열려 자켓이나 코트처럼 입을 수 있는지 확인하세요. 앞 전체가 막힌 니트·후드티·반집업, 아동 우주복 같은 일체형은 기타로 확인해야 할 수 있습니다. 자동 분류가 이런 옷을 놓칠 수 있으니 사진을 보고 직접 고르세요.

## 9. 사진을 크게 보거나 다른 각도 보기

사진을 **더블클릭**하면 크게 볼 수 있습니다. 확대창에서 마우스 휠을 움직이면 확대·축소되고, 확대한 상태에서 드래그하면 사진 위치를 움직일 수 있습니다. **전체 맞춤**을 누르면 사진 전체가 다시 보입니다.

다른 각도 사진이 있다면 확대창의 각도 목록에서 바꿔 보세요. **← 이전 옷**, **다음 옷 →**으로 다른 옷도 확인할 수 있습니다. 확대창을 닫으려면 **Esc** 또는 **닫기**를 사용합니다.

작업 화면의 아래쪽 **←**, **→**나 키보드 좌우 방향키로 페이지를 이동합니다. 입력칸이나 팝업을 조작 중일 때는 그 창의 키 조작이 먼저 적용됩니다. 페이지가 안 넘어가면 목록이나 확대창을 닫고 다시 눌러 보세요.

## 10. 보기 설정과 화면 배치 바꾸기

**배치**에서 원하는 행과 열을 선택하면 한 화면에 보이는 옷 수가 바뀝니다. 1행×1열부터 4행×4열까지 고를 수 있습니다. 글자나 사진을 크게 확인하려면 적게, 여러 벌을 빠르게 훑으려면 많이 표시하세요.

위쪽 **점 세 개 → 보기 설정**에서는 다음을 바꿀 수 있습니다.

| 설정 | 사용할 때 |
|---|---|
| 사진 + 입력 | 사진 옆에서 분류값을 확인하고 수정할 때 사용합니다. |
| 사진만 보기 | 입력칸 없이 사진 위주로 훑을 때 사용합니다. |
| 빠른 입력 | 선택 목록 대신 펼쳐진 버튼으로 값을 빠르게 고릅니다. |
| 사진만 볼 때 정면 사진만 표시 | 정면만 볼지, 다른 각도도 함께 볼지 고릅니다. |
| 사진 확대 | 사진 표시 크기를 조절합니다. |

보기나 배치를 바꿔도 이미 입력한 값은 유지됩니다. 해·달 아이콘으로 화면 밝기도 바꿀 수 있으며, 마지막으로 고른 테마를 기억합니다.

## 11. 옷 번호 검색과 분류 필터

특정 번호를 보려면 **옷 번호 검색**에 번호를 입력합니다. 다시 전체 번호를 보려면 검색어를 지우세요.

**분류**를 누르면 카테고리·성별·사이즈·성인/아동 조건을 고를 수 있습니다. 예를 들어 카테고리를 코트, 성별을 여성으로 고르면 **여성 코트에 해당하는 옷**만 보입니다. 여러 조건은 모두 만족해야 합니다.

조건에 맞는 옷이 없으면 **전체 보기**로 돌아가세요. 분류 창의 **초기화**는 분류 조건을 지웁니다. 옷을 못 찾겠다면 검색어, 확인 필요 필터, 분류 조건이 남아 있는지도 확인하세요.

필터는 화면에서 찾아보기 위한 기능입니다. **엑셀에는 현재 보이는 카드만이 아니라 그 작업의 전체 대상이 저장**되므로, 일부 번호만 저장할 생각이라면 작업 범위와 제외 번호를 먼저 확인하세요.

## 12. 안내판이 잘못 잡혔을 때

안내판 글자가 잘 안 읽히거나 다른 부분을 보고 분석한 것 같으면 **머리 확대**에서 안내판을 확인합니다. 사진 확대창에서 **머리 확대**를 열 수도 있습니다.

1. 해당 옷의 사진을 크게 열고 **머리 확대**를 누릅니다.
2. **머리 영역 지정**을 누릅니다.
3. 안내판의 머리 전체와 글자가 들어가도록 마우스로 드래그합니다.
4. **머리 확대**에서 **이 옷만 다시 분석**을 누릅니다.
5. 결과를 보고 필요한 값을 고치고 확인합니다.

다른 각도 사진을 분석에 쓰려면 확대창에서 각도를 고르고 **정면으로**를 누릅니다. 지정한 영역을 취소하고 프로그램이 찾은 위치를 쓰려면 **자동 위치 사용**을 누르세요.

영역 지정은 분석할 부분을 고르는 기능입니다. 원본 사진을 실제로 잘라 저장하거나 글자를 바꾸는 기능은 아닙니다.

## 13. 한 벌 또는 작업 전체 다시 분석하기

한 벌만 다시 보고 싶다면 **머리 확대 → 이 옷만 다시 분석**을 사용하세요. 다른 옷의 분석을 처음부터 다시 할 필요가 없습니다.

작업 전체의 분석 결과를 다시 계산하려면 **점 세 개 → 고급 설정 → 작업 전체 다시 분석**을 누릅니다. 기존 완료 결과도 다시 계산하므로 일반 분석보다 시간이 더 걸릴 수 있습니다.

재분석은 사람이 입력·확인한 값을 무조건 덮어쓰는 기능이 아닙니다. 새 결과가 나와도 현재 입력값이 맞는지 직접 확인해 주세요.

## 14. 사진 범위와 제외 번호 바꾸기

**점 세 개 → 고급 설정 → 사진 범위 / 에러번호 / 폴더**를 엽니다. 시작 번호·끝 번호·에러번호를 바꾼 뒤 **사진 범위와 에러번호 저장**을 누릅니다.

예를 들어 1~100번 작업을 1~200번으로 늘리면 새 번호의 사진을 추가로 확인할 수 있습니다. 범위를 줄여도 이전 입력은 보관되며, 다시 늘리면 이어서 표시됩니다.

범위를 1~100번으로 바꾸는데 에러번호에 150이 남아 있다면 함께 수정해야 합니다. 변경 내용은 현재 작업에 적용되며, 다른 작업이나 이미 저장한 엑셀은 자동으로 바뀌지 않습니다.

사진 폴더를 옮겼다면 같은 창의 **옮긴 사진 폴더 다시 연결**을 누르고, 번호 폴더들이 있는 새 상위 폴더를 고르세요. 기존과 같은 번호 구조인지 확인해 주세요.

## 15. 분석 기준은 처음에는 그대로 사용하세요

**점 세 개 → 고급 설정 → 분석 기준**에서 판넬 위치·성별/성인·아동·사이즈·옷 소매의 확인 기준을 바꿀 수 있습니다. 기본값은 90%이며, 기장 기준은 90%로 표시됩니다.

기준을 높이면 사람이 확인할 옷이 늘어날 수 있고, 낮추면 확인 표시가 줄어들 수 있습니다. 기준을 낮춘다고 모델이 글자를 더 잘 읽는 것은 아닙니다. **처음 사용할 때는 기본값을 유지하고 사진을 보며 확인하는 방식**으로 사용하세요.

기준을 바꿨다면 **기준 저장**을 누릅니다. 저장한 점수에 따라 확인 필요 표시가 달라질 수 있으니 다시 살펴보세요.

## 16. 엑셀 파일로 저장하기

모든 대상 옷의 네 항목을 채우고 필요한 확인을 마쳤다면 다음 순서로 저장합니다.

1. 위쪽 **엑셀로 저장**을 누릅니다.
2. 처음 저장한다면 **새 엑셀 파일**로 위치와 이름을 정합니다. 이어 붙일 파일이 있다면 **기존 엑셀 파일 선택**을 누릅니다.
3. **새 시트 이름**을 확인합니다. 기본은 촬영일입니다.
4. **미리보기**를 누릅니다.
5. 대상 수량과 번호·외투코드·카테고리·성별·연령·사이즈를 확인합니다.
6. **새 시트에 저장**을 누릅니다.
7. 완료 안내를 확인합니다. 필요하면 엑셀 저장 창을 다시 열어 **저장한 파일 열기**를 누릅니다.

같은 엑셀 파일에 날짜별로 시트를 추가할 수 있습니다. 같은 시트 이름이 있으면 `(2)`, `(3)`을 붙여 새 시트를 만들며, 기존 시트를 덮어쓰지 않습니다.

엑셀에는 분류값과 사진 식별자가 들어갑니다. 실제 사진 파일을 엑셀 안에 넣거나 인터넷에 올리는 것은 아닙니다.

미리보기 뒤 값을 수정했다면 다시 **미리보기**를 만드세요. 대상 엑셀 파일을 다른 프로그램에서 수정한 경우에도 다시 미리보기가 필요합니다. Excel에서 파일을 열어 둬 저장이 막히면 Excel을 닫고 재시도하세요.

저장 중에는 저장 중인 작업의 입력을 잠시 바꿀 수 없습니다. 홈이나 다른 작업으로 이동할 수는 있습니다. 완료 안내가 나올 때까지 기다려 주세요.

## 17. 작업 이어 하기와 작업 관리

입력·검수 상태는 자동 저장됩니다. 앱을 닫았다 다시 열면 홈에서 이전 작업 카드를 골라 이어 하세요. 열려 있던 작업 탭과 보기 설정도 보관합니다.

작업 이름을 바꾸려면 홈 작업 카드의 **점 세 개 → 이름 변경**을 사용하세요. 작업 화면의 **점 세 개 → 작업 관리 → 이름 변경**에서도 바꿀 수 있습니다.

작업을 지우려면 **작업 삭제…**를 고르고 안내를 확인합니다. 이 작업의 입력·검수·분석 기록이 삭제되며 **되돌릴 수 없습니다**. 원본 사진과 이미 저장한 엑셀 파일은 그대로 남습니다. 잠깐 화면에서 닫으려는 것이라면 삭제 대신 아래쪽 탭의 **×**를 누르세요.

이 프로그램은 기본적으로 같은 PC에서 작업을 이어 하는 방식입니다. 설치파일만 다른 PC로 복사한다고 작업 기록까지 함께 옮겨지는 것은 아닙니다. 작업 기록 폴더나 원본 사진을 임의로 지우지 마세요.

## 18. 자주 생기는 상황과 해결 방법

| 이런 상황인가요 | 먼저 이렇게 해 보세요 |
|---|---|
| 사진이 하나도 안 나옵니다. | 번호 폴더들이 들어 있는 상위 폴더를 골랐는지, 번호 범위가 맞는지 확인합니다. |
| 특정 옷이 안 보입니다. | 검색어·분류·확인 필요 필터, 에러번호, 작업 범위를 확인합니다. |
| 사진을 옮긴 뒤 안 보입니다. | 고급 설정에서 옮긴 사진 폴더 다시 연결을 사용합니다. |
| 분석 결과가 틀렸습니다. | 입력값을 직접 고칩니다. 안내판 위치가 이상하면 머리 영역을 지정하고 이 옷만 다시 분석합니다. |
| 값이 있는데 계속 확인 필요라고 나옵니다. | 네 항목을 확인한 뒤 해당 옷의 확인 버튼을 누릅니다. 아동 성별도 확인합니다. |
| 새 시트에 저장 버튼이 눌리지 않습니다. | 빈칸·확인 필요가 남았는지 보고, 파일과 시트 이름을 정한 다음 미리보기를 만듭니다. |
| 엑셀이 사용 중이라고 나옵니다. | Excel이나 해당 파일을 열어 둔 프로그램을 닫고 다시 시도합니다. |
| 미리보기 후 내용이 바뀌었다고 나옵니다. | 현재 값과 파일을 확인한 뒤 미리보기를 다시 만듭니다. |
| 화면이 깨지거나 안 보입니다. | 시작 메뉴의 호환 모드로 실행해 봅니다. |
| 작업 탭을 닫았습니다. | 홈에서 같은 작업 카드를 다시 엽니다. |
| 저장 확인 필요 또는 오류가 표시됩니다. | 오류 안내를 확인합니다. 저장 위치의 권한·남은 공간을 확인하고, 해결될 때까지 완료로 생각하지 않습니다. |

사용 중 문제가 생기면 표시된 오류 문구와 작업 이름·옷 번호를 함께 기록해 두세요. 원본 사진이나 기존 엑셀을 지우면서 문제를 해결하려고 하지는 마세요.

## 19. 작업을 마치기 전 확인할 것

1. 오늘 처리할 번호 범위와 제외 번호가 맞는지 확인합니다.
2. 옷 분류·사이즈·성별·연령의 빈칸을 채웁니다.
3. 확인 필요 표시와 아동 성별을 확인합니다.
4. 엑셀 미리보기의 대상 수량과 내용을 확인합니다.
5. **새 시트에 저장**을 누르고 완료 안내까지 확인합니다.

평소에는 **작업 열기 → 분석 → 확인·수정 → 엑셀 저장** 순서만 기억하면 됩니다. 보기 설정과 고급 설정은 필요할 때 이 매뉴얼에서 해당 항목을 찾아 사용하세요.
